### File Format
- ZIP containing pipe-delimited text file(s)
- Columns: `SETTLEMENT DATE|CUSIP|SYMBOL|QUANTITY (FAILS)|DESCRIPTION|PRICE`
- Date: YYYYMMDD
- Header line exists: "SETTLEMENT DATE|CUSIP|SYMBOL|QUANTITY (FAILS)|DESCRIPTION|PRICE"
- QTY: integer, may have commas
- PRICE: float, may be "." (skip those)

### Threshold Criteria (Reg SHO Rule 203(b)(3))
A security is "on the threshold list" on a settlement date iff:
`QUANTITY (FAILS) * PRICE > $500,000`

### Episode Definition
- Episode starts when a ticker first appears on threshold list.
- Continues as long as ticker remains on list on consecutive settlement dates.
- Gap of 5+ calendar days off the list → new episode.
- `dwell` = (exit_date - entry_date).days
