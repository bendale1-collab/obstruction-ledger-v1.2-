# K1-1 — quote-vs-anchor byte match: K1a fixtures (Claude-authored)

Convention: a directory per case with anchor.txt and report.md. A quoted block
is a fenced ``` block immediately preceded by `QUOTE-OF: <anchor>` (or
`VERBATIM FROM <anchor>`, a claim of verbatim). Content must equal the anchor
byte-for-byte, trailing newline and line endings included. A `DERIVED <rev>`
line before the QUOTE-OF line exempts the block. No case labels in parsed
content; report.md has no header line. MEASUREMENTS.txt was generated by
hashing both sides; the expected column is copied from it.

## Positives (must report MISMATCH)
| case | expected | rationale | hard |
|---|---|---|---|
| p-indent-flattened | MISMATCH | continuation indentation flattened (Rev D, Rev F incidents) | Y |
| p-trailing-newline-dropped | MISMATCH | trailing newline dropped (Rev E incident) | Y |
| p-line-omitted | MISMATCH | one line omitted | Y |
| p-condensed | MISMATCH | condensed rendering (RENDERING-AS-RECORD) | Y |
| p-crlf | MISMATCH | CRLF vs LF anchor | Y |
| p-one-char-changed | MISMATCH | one character in GIT_HEAD | Y |
| p-stray-line-inside | MISMATCH | agent prose appended inside the quote (Rev D stray line) | Y |
| p-lines-reordered | MISMATCH | same lines, reordered | Y |
| p-spaces-collapsed | MISMATCH | double spaces collapsed | Y |
| p-verbatim-claim-wrong-revision | MISMATCH | claims VERBATIM; anchor is a different revision | Y |

## Hard negatives
| case | expected | rationale | hard |
|---|---|---|---|
| n-exact | MATCH | byte-identical; same anchor as every positive | Y |
| n-derived-flattened | DERIVED (skip) | same flattened block as p-indent-flattened; differs only in the DERIVED header | Y |
| n-both-crlf | MATCH | same CRLF block as p-crlf; differs only in the anchor also being CRLF | Y |

## Properties (properties.py; no check code referenced; MIN_EXAMPLES = 200)
- exact_quote: random anchor bytes quoted exactly, with or without trailing
  newline. Must be MATCH.
- derived_any: any content under a DERIVED header. Must produce no finding.
Both verified to generate 200 examples without error before commit.
