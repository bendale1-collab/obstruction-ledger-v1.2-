Convention (git-free fixture mode): seal/, head/, MANIFEST (one sealed path
per line), head/ledger/*.md as candidate declaring entries. A declaring entry
is any head/ledger/*.md other than the diverging path whose text contains the
path string. Section headers use words, not numerals. No case labels in parsed
content. MEASUREMENTS.txt was generated by hashing and grepping; the expected
column is copied from it.

(standing-rules.md, K1 section): the declaring-entry criterion accepts
incidental mention, and nature classification has varied across runs. These
fixtures test the criterion as sealed; they do not resolve either.
